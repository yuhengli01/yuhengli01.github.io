HyCO: A Hybrid Neural Solver for Combinatorial Optimization
Yuheng Li*, Di Yang*, Haipeng Chen†, Yanhai Xiong† (* equal contribution)
NeurIPS 2026 (Poster)
arxiv code
Reinforcement Learning Diffusion Model Combinatorial Optimization
Key Points
  • Problem RL solvers accumulate compounding errors over long horizons, while diffusion solvers pay regret that grows with the unsolved subspace: complementary failure modes.
  • Method Build a solution prefix with RL, then adaptively hand off to a conditional diffusion model to finish; the trigger uses policy entropy + RL–DM disagreement.
  • Theory The hybrid has strictly lower expected regret than either backbone, with a unique optimal trigger step.
  • Results Consistent gains over both RL and DM backbones across diverse CO benchmarks.
VTV-FM: Flow Matching through Variational Terminal-Velocity Closure
Haoyang Jiang*, Yuheng Li*, Di Yang*, Yanhai Xiong, Haipeng Chen†, Yi He† (* equal contribution)
NeurIPS 2026 (Poster)
arxiv code
Flow Matching Generative Model
Key Points
  • Problem Flow matching uses first-order, straight-line bridges, so even OT pairing can't model curvature or acceleration; second-order bridges need a terminal velocity that static data lacks.
  • Method Derive the missing terminal velocity by minimizing acceleration energy, giving a closed-form closure for static data.
  • Unified design The same minimum-acceleration principle also defines the OT pairing cost and the acceleration training targets.
  • Results Better transport geometry and generation quality than first- and high-order FM baselines on 2D data, PDE physical fields, and CIFAR-10.
Can Reinforcement Learning Solve Asymmetric Combinatorial-Continuous Zero-Sum Games?
Yuheng Li, Panpan Wang, Haipeng Chen
ICLR 2025 (Poster)
arxiv code poster slides
Multi-Agent Reinforcement Learning Game Theory
Key Points
  • New model First to define ACCES games: two-player zero-sum games where one player has a combinatorial strategy space and the other an infinite, continuous one, a structure that arises in combinatorial optimization under adversarial or uncertain parameters (routing, patrolling, security games).
  • Theory Prove a mixed Nash equilibrium exists via finite-game approximation, establishing the weak sequential compactness and continuity it requires.
  • Method CCDO, a combinatorial–continuous double-oracle solver with convergence guarantees; CCDO-RL uses RL to compute approximate best responses for the NP-hard combinatorial player, with a new convergence analysis.
  • Results Converges to NE on adversarial covering salesman, capacitated VRP, and patrolling games; beats baselines across adversary types and problem sizes, especially in generalization.
LENS: Learning to Navigate with Active Search for Partially Observable MAPF in Unknown Environments
Di Yang, Yuheng Li, Yanhai Xiong
Transactions on Machine Learning Research (TMLR)
paper openreview
Diffusion Model Multi-Agent Path Finding
Key Points
  • Problem Partially observable MAPF: a team must navigate and coordinate in an environment it discovers as it moves.
  • Method Local search over anticipated conflict groups, guided by a learned continuous potential field (U-Net + FiLM) that captures long-horizon structure and helps agents pass bottlenecks.
  • Guarantee A conflict-resolution cascade (L-CBS, coordinated retreat, push-and-rotate) ensures locally collision-free motion, with no large-scale end-to-end policy learning.
