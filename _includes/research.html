Research Interests

My research focuses on building agents that are capable, efficient, and reliable for complex real-world decision-making (e.g., multi-step planning under hard constraints, adversarial settings), using large language models (including diffusion language models) and reinforcement learning — I care not only about whether a model performs well, but about why it works and whether we can trust it in practice.

Current Focus
  • Evaluating LLM agents (ongoing): building verifiable environments with deterministic judges (rubric-based rules), and budget-matched protocols for comparing test-time search and recursive self-improvement (RSI) methods
  • Diffusion language models: arbitrary-order generation, i.e., deciding which tokens to generate and when instead of fixed left-to-right decoding, and the design of token embeddings for diffusion-based text generation
  • RL post-training for diffusion / semi-autoregressive language models: adapting RL fine-tuning (e.g., GRPO-style methods) to models that do not generate strictly left to right
Questions I'm Currently Exploring
  • Can LLM agents reliably improve themselves from verifier feedback, and how should we measure it?
  • Does generation order matter for diffusion language models, and can it be learned?
